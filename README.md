# Photography & Gallery

A Django-based photography gallery application with user authentication, image uploads, and gallery views.

## Run locally

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Set `DJANGO_SECRET_KEY` to a development secret.
4. Run migrations with `python photography/manage.py migrate`.
5. Start the server with `python photography/manage.py runserver`.
